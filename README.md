# Audit terrain — Régie Access

Application hors ligne pour relever un audit d'accessibilité sur le terrain (texte, dictée, photos, questionnaire facultatif), puis l'envoyer par mail au rédacteur d'audit.

- Aucune donnée n'est envoyée sur Internet, sauf quand l'utilisateur envoie lui-même le mail.
- Fonctionne dans le navigateur (Mac, Windows, iPhone, Android), sans store ni abonnement.
- Format d'export : `audit.md` + photos (voir la spécification partagée avec le rédacteur).

État : **maquette cliquable (étape 2)**. Les données restent en mémoire et disparaissent à la fermeture.

Fichiers : `index.html`, `style.css`, `app.js` (écrans), `parties.js` (catalogue des parties et questions), `rappels.js` (rappels théoriques courts).
